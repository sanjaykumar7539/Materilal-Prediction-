# CampusMind chat

The chat workspace is an Operate surface: reading, composing, and revisiting conversations take priority. The interface uses a pale slate navigation rail, white conversation canvas, and restrained forest green accents. System typography keeps it usable offline without font requests.

The desktop layout has a 264px navigation rail and a centered conversation column up to 760px. The mobile rail opens behind a dismissible overlay. The composer stays beneath the scrolling conversation. Settings use an anchored panel, and the first conversation offers three editable prompt starters.

Use 14px body text, 12px control labels, 10px metadata, and a 32–46px welcome heading. Borders are pale slate; corners range from 6px controls to 14px for the composer. Use authored Lucide icons consistently. Green indicates the primary action and model readiness. Amber indicates an unavailable model; errors include actionable backend text.

Support visible keyboard focus, reduced motion, disabled actions while generating, stream cancellation, failed and empty responses, and browser storage failures. Markdown renders without raw HTML. Conversations persist only in local browser storage and export as Markdown.
